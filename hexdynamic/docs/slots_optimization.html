优化后实现

class DeploymentSolution:
    __slots__ = ('cameras', 'camps', 'drones', 'rangers', 'fences', '_cache_key')
    
    def __init__(self, cameras, camps, drones, rangers, fences):
        self.cameras = cameras
        self.camps = camps
        self.drones = drones
        self.rangers = rangers
        self.fences = fences
        self._cache_key = None  # 必须显式初始化
    
    def __getstate__(self):
        """pickle 支持"""
        return {slot: getattr(self, slot) for slot in self.__slots__}
    
    def __setstate__(self, state):
        """pickle 支持"""
        for slot, value in state.items():
            setattr(self, slot, value)

实施挑战

挑战 1: dataclass 与 __slots__ 冲突

field(default=None, init=False) 与 __slots__ 不兼容。

解决方案： 手写 __init__，移除 @dataclass 装饰器。

挑战 2: _cache_key 初始化

__slots__ 不支持默认值，必须在 __init__ 中显式初始化。

挑战 3: copy.copy() 浅拷贝语义

s1 = DeploymentSolution(cameras={0: 1}, ...)
s2 = copy.copy(s1)  # 浅拷贝，共享内部 dict
s2.cameras[0] = 99  # 影响 s1！

影响： 需要确保所有拷贝操作是深拷贝或有意共享。

挑战 4: pickle 不兼容

__slots__ 对象默认不可 pickle，需要实现 __getstate__/__setstate__。

实施步骤

  1. 移除 @dataclass 装饰器
  2. 手写 __init__ 方法
  3. 添加 __slots__ 定义
  4. 初始化 _cache_key = None
  5. 添加 __getstate__/__setstate__ (pickle 支持)
  6. 更新所有 DeploymentSolution() 调用点
  7. 验证 copy.copy() 行为
  8. 运行完整测试套件

风险评估

风险 严重性 缓解措施
与 dataclass 冲突 HIGH 手写 __init__
