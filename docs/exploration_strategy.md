探索范围需要在"探索"和"开发"之间取得平衡。

## 范围过大的问题

### 1. 搜索效率下降

```
假设解空间是 [0, 100]，当前解在 50 附近

α ∈ [-2, 2]:  搜索范围较集中，效率高
α ∈ [-10, 10]: 搜索范围过大，大量无效尝试
α ∈ [-100, 100]: 几乎是随机搜索，失去方向性
```

### 2. 收敛困难

```
迭代 1: current = 50, α = 50 → new = 3000 (超出解空间)
迭代 2: current = 50, α = -30 → new = -1500 (超出解空间)
迭代 3: current = 50, α = 80 → new = 5000 (超出解空间)
...
```

大量迭代都在无效区域，无法收敛到最优解。

### 3. 破坏已有成果

```
当前已找到较好的解：current = 60, best = 65

α ∈ [-2, 2]:  new ≈ [30, 100]，可能找到更好的解
α ∈ [-10, 10]: new ≈ [-400, 560]，可能跳到很差的解
```

过大的探索可能丢弃已积累的好解。

---

## 范围选择的原则

### 1. 与解空间匹配

```python
# 如果解向量每个元素范围是 [0, 10]
α ∈ [-2, 2] 合适

# 如果解向量每个元素范围是 [0, 1000]
α ∈ [-20, 20] 可能更合适
```

### 2. 与问题特性匹配

| 问题类型 | 推荐范围 | 原因 |
|---------|---------|------|
| 连续优化 | [-2, 2] | 解空间平滑，小步探索足够 |
| 组合优化 | [-1, 1] 或更小 | 离散解空间，大步长容易无效 |
| 多峰问题 | [-3, 3] | 需要跳出局部最优 |

### 3. 动态调整策略

```python
# 早期：大范围探索
if iteration < max_iterations * 0.3:
    α_range = 3.0

# 中期：逐渐收敛
elif iteration < max_iterations * 0.7:
    α_range = 2.0

# 后期：精细搜索
else:
    α_range = 1.0
```

## DSSA 的平衡策略

```python
# 开发模式（R2 < ST）：保守搜索
new_vector = current_vector + np.random.uniform(0, 1, ...) * (best_vector - current_vector)
# α ∈ [0,1]，向最优解靠拢

# 探索模式（R2 >= ST）：适度探索
new_vector = current_vector + np.random.uniform(-2, 2, ...)
# α ∈ [-2,2]，但不是基于方向向量，而是纯随机扰动
```

**注意**：DSSA 的探索模式用的是 `np.random.uniform(-2, 2)` 直接加到 current_vector，而不是乘以方向向量。这是**纯随机探索**，与开发模式不同。

---

## 总结

| 范围 | 优点 | 缺点 |
|------|------|------|
| 太小 | 收敛快 | 易陷入局部最优 |
| 适中 | 平衡探索与开发 | - |
| 太大 | 可能找到全局最优 | 效率低、收敛难、破坏已有成果 |

**核心原则**：探索范围应该足够大以跳出局部最优，但又不能太大导致搜索效率过低。
